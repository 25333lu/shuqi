# 纾炽Ai绘图 (shuqi)

一个功能强大的AI图像生成Web应用，支持多种AI模型和参数配置。

## 功能特点

- 🎨 支持两种AI模型：Nano Banana Pro 和 GPT Image 2
- 📐 11种画幅比例选择（1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 5:4, 4:5, 21:9, 自动）
- 🖼️ 支持参考图片上传（最多8张）
- 📱 响应式设计，支持桌面和移动设备
- 📚 完整的历史记录管理
- 💾 图片预览、下载功能
- 🔍 实时进度显示
- 💰 积分查询功能

## 使用方法

1. 在浏览器中打开应用
2. 输入创意描述（支持中英文）
3. 选择模型和参数
4. 可选上传参考图片
5. 输入API Key（妙笔支持的Key）
6. 点击"生成"开始创作

## 技术栈

- 纯HTML/CSS/JavaScript
- 无外部依赖
- 响应式设计
- 现代化UI（玻璃态效果）
- 本地存储

## API集成

- **Nano Banana Pro**: `https://grsai.dakka.com.cn/v1/draw/nano-banana`
- **GPT Image 2**: `https://grsai.dakka.com.cn/v1/draw/completions`
- **结果查询**: `https://grsai.dakka.com.cn/v1/draw/result`
- **积分查询**: `https://grsai.dakka.com.cn/client/openapi/getAPIKeyCredits`

## 特色功能

### 1. 多模型支持
- **Nano Banana Pro**: 专业的AI图像生成模型
- **GPT Image 2**: OpenAI的图像生成模型

### 2. 灵活的参数配置
- **画幅比例**: 11种预设比例，支持自动选择
- **分辨率**: 1K标准、2K高清、4K超清
- **参考图片**: 支持拖拽上传，最多8张

### 3. 用户体验优化
- **实时反馈**: 显示生成进度和状态
- **历史管理**: 完整的生成记录，支持分页查看
- **图片管理**: 大图预览、下载、复制功能
- **键盘快捷键**: ESC关闭，左右箭头切换图片

### 4. 现代化界面
- **玻璃态UI**: 现代化的毛玻璃效果
- **响应式设计**: 完美适配桌面和移动设备
- **深色主题**: 护眼的深色界面
- **动画效果**: 流畅的交互动画
